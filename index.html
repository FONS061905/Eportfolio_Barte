    Learning Reflections

    IT Journal

    Weekly reflections from my IT coursework during AY 2025–2026.

    Introduction Week 1

    Course Orientation & Overview of IT

    The first week introduced the course structure, expectations, and the IT field overview. We discussed the role of IT professionals in today's digital landscape and set the foundation for the semester ahead.

    Web Development Week 2

    HTML5 Fundamentals & Document Structure

    We explored the building blocks of the web — HTML5 tags, semantic elements, forms, and proper document structure. I practiced creating my first structured web pages from scratch.

    Styling Week 3

    CSS3 & Page Styling Techniques

    This week covered CSS selectors, the box model, typography, colors, and positioning. I learned how to style elements and create visually organized layouts with different design approaches.

    Responsive Design Week 4

    CSS Flexbox, Grid & Responsive Layouts

    We dove into Flexbox and Grid, learning to build responsive designs that adapt to different screen sizes. Media queries and mobile-first design principles were key takeaways.

    JavaScript Week 5

    JavaScript Basics & DOM Manipulation

    Introduction to JavaScript: variables, data types, functions, and control flow — then DOM manipulation, selecting elements and responding to user events to make pages interactive.

    Programming Week 6

    Algorithms & Problem Solving

    Computational thinking — breaking problems into logical steps, pseudocode, and implementing algorithms. We practiced sorting, searching, and iteration to sharpen problem-solving skills.

    Database Week 7

    Introduction to Databases & SQL

    Relational database concepts — tables, relationships, primary/foreign keys — and basic SQL queries for CRUD operations. Understanding data storage and retrieval is essential for any IT system.

    Midterm Week 8

    Midterm Project & Review

    Midterm brought everything together. I applied HTML, CSS, and JS in a culminating project, reviewing key concepts and identifying areas for improvement going into the second half.

    Advanced Topics Weeks 9 – 18

    Second Half — Advanced Concepts

    Back-end integration, server-side concepts, collaborative development, and final project work. These weeks solidified my understanding of full-stack development and IT systems as a whole.
